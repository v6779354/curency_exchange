# Конвертер валют с кешем

Telegram-бот на Python: получает официальные курсы ЦБ РФ, считает валютные пары
и сокращает количество сетевых запросов с помощью `dict` и SQLite.
Поддерживает личные заметки. Стек: pyTelegramBotAPI, requests, SQLite, pytest.

## Запуск за 5 минут

Нужен Python 3.10+ и токен Telegram-бота от BotFather. Ключ валютного API не нужен.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# Только если .env ещё нет:
cp .env.example .env
# Укажите TELEGRAM_BOT_TOKEN в .env
python main.py --check
python main.py
```

В этом рабочем каталоге `.venv` уже подготовлен, старый токен остаётся в `.env`.
Существующий `.env` не перезаписывайте. `CURRENCY_API_KEY` от старого проекта
больше не используется. Для обычного запуска достаточно активации `.venv` и
`python main.py`. Совместимый запуск: `python bot.py`.

`--check` проверяет токен и отсутствие webhook, выводит имя бота, не запускает
polling и не отправляет сообщения. Откройте указанный аккаунт и отправьте `/start`.
Остановка — Ctrl+C. Запускайте только один процесс на этот токен и базу, включая
прежний кошелёк: иначе Telegram вернёт конфликт 409. При установленном webhook
сначала отключите его в прежнем приложении.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | обязательна | Токен прежнего или нового бота |
| `CACHE_TTL_SECONDS` | `3600` | Срок свежести в секундах, целое положительное число |
| `DATABASE_PATH` | `currency.sqlite3` | Относительный путь от корня проекта или абсолютный путь |

Если локальный Python на macOS сообщает об ошибке сертификата при установке,
используйте `PIP_CERT=/etc/ssl/cert.pem pip install -r requirements.txt`. Проверка
TLS остаётся включённой.

База создаётся автоматически; родительский каталог должен существовать.
`.env`, базы, `.venv` и служебные файлы исключены из Git.

## Примеры

```text
USD RUB
1 USD = 90 RUB
Курс ЦБ на 2026-09-26 · источник: API ЦБ

100 usd rub
100 USD = 9000 RUB
Курс ЦБ на 2026-09-26 · источник: кеш
```

Числа выше демонстрационные. Бот показывает реальные данные источника.
Принимаются десятичные суммы с точкой или запятой, до 8 знаков, больше нуля
и не больше 1 триллиона. Результат округляется до 6 знаков; вычисления — `Decimal`.

- `/start`, `/help` — справка.
- `/currencies` — поддерживаемые источником коды валют.
- `/add Оплатить счёт поставщика` — сохранить личную заметку, до 1000 символов.
- `/list` — заметки по 5 штук; команда следующей страницы указана в ответе.

Бот работает в личных чатах. Заметки фильтруются по Telegram user ID и сохраняются
после перезапуска. Старые кнопки кошелька предлагают открыть `/start`.

## Как работает кеш

```text
Запрос → проверка формата → dict["USD_RUB"]
  свежая пара → ответ
  пары нет / TTL истёк → проверка сохранённого набора курсов
    набор свежий → вычисление пары → SQLite + dict → ответ
    набор устарел → API ЦБ → SQLite + память → вычисление пары → ответ
```

`dict` обеспечивает поиск по ключу за O(1) в среднем. SQLite служит постоянным
хранилищем, а не заменой in-memory кеша. При старте пары и набор курсов загружаются
в память. Чтение готовой свежей пары не обращается ни к SQLite, ни к API.

ЦБ отдаёт набор валют одним запросом. Поэтому запрос новой пары внутри TTL
использует тот же набор. Курс пары A/B = (RUB за 1 A) / (RUB за 1 B).
Номинал валюты учитывается, RUB имеет базовое значение 1.

Свежесть: `0 <= now - updated_at < TTL`. На границе TTL запись уже устарела.
`updated_at` — время успешного получения набора (Unix timestamp UTC),
`rate_date` — отдельная официальная дата курса. Производные пары наследуют
время набора: их вычисление и перезапуск не продлевают TTL.

Таблицы:

- `currency_cache(pair PRIMARY KEY, value, updated_at, rate_date)` — пары.
- `rate_snapshot(currency PRIMARY KEY, value, updated_at, rate_date)` — набор ЦБ.
- `notes(id, user_id, text, created_at)` — личные заметки.

Значения Decimal сохраняются как TEXT без преобразования в float.
Обновление набора и очистка прежних пар выполняются одной транзакцией.
Блокировка объединяет одновременные промахи кеша в одном процессе: один запрос
обновляет набор, остальные используют результат. Многопроцессный режим не поддерживается.

Таймаут соединения — 5 секунд, чтения — 15 секунд. При сетевой ошибке или
некорректном ответе прежние данные сохраняются, но устаревший курс не выдаётся
как свежий. Следующая попытка API допускается через 15 секунд, чтобы сбой
не вызвал поток повторных запросов. Ошибки валюты и пустой ввод объясняются
пользователю. Логи содержат `cache_hit` / `cache_miss`, токен маскируется.

## Источник и ограничения

[Официальный XML-интерфейс Банка России](https://www.cbr.ru/development/sxml/):
`https://www.cbr.ru/scripts/XML_daily.asp`. Используется последняя опубликованная
дата. Это официальные курсы, не котировки биржи в реальном времени и не курс
покупки/продажи конкретного банка. TTL ограничивает обращения, но не означает,
что ЦБ публикует новый курс каждый час. Доступны только валюты из ответа ЦБ.

## Проверки

```sh
pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты используют временную SQLite и поддельный API: без токена, сети и отправки
сообщений. Проверяют hit/miss, границу TTL, возраст производной пары, восстановление
после перезапуска, конкурентные запросы, ошибки сети/XML, номинал, ввод и
изоляцию заметок. Текущее время передаётся зависимостью — тестам не нужен sleep.

Для проверки кеша вручную задайте `CACHE_TTL_SECONDS=30`, запустите бот и дважды
отправьте `USD RUB`: сначала источник API, затем кеш. Через 30 секунд запрос
обновит набор. Перезапуск внутри TTL использует SQLite без повторного API.

## Структура

```text
api/cbr.py              — HTTPS и разбор XML
cache/memory.py         — dict, запись кеша, TTL
database/store.py      — SQLite и транзакции
services/converter.py  — парсинг, конвертация и обновление кеша
bot/handlers.py        — Telegram-команды
config.py              — .env и проверка настроек
diagnostics.py         — проверка Telegram и безопасные логи
main.py                — сборка и запуск
bot.py                 — совместимый запуск
tests/                 — автоматические проверки
legacy/                — исходные наработки кошелька для справки
```

`legacy/` хранит прежний код и README как архив, не участвует в новом приложении.
Архивные тесты исключены из текущего набора. Существующий `wallet.sqlite3`
не изменяется. Новое приложение использует отдельную базу.

## Для портфолио

**Сервис конвертации валют с оптимизированным кешированием данных.**
Интеграция внешнего API, двухуровневый кеш с TTL, восстановление из SQLite,
защита от параллельных обновлений, обработка сетевых ошибок и автоматические тесты.
